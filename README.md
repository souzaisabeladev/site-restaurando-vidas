# 🌱 Restaurando Vidas

**Desenvolvimento de uma plataforma web institucional para apresentação de uma iniciativa social.**

🔗 **Acesse o projeto:** [Restaurando Vidas](https://site-restaurando-vidas.vercel.app)

## 📌 Sobre o projeto

O Restaurando Vidas é um projeto de desenvolvimento web criado para apresentar uma iniciativa institucional por meio de uma interface digital.

O objetivo é proporcionar uma experiência de navegação organizada, apresentar informações institucionais e destacar conteúdos visuais por meio de uma galeria de imagens.

## 🚀 Funcionalidades

- Página institucional.
- Apresentação de informações do projeto.
- Identidade visual com logotipo institucional.
- Galeria de imagens.
- Interface organizada e navegação intuitiva.

## 🛠️ Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS

## 💻 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/souzaisabeladev/site-restaurando-vidas.git
```

Entre na pasta:

```bash
cd site-restaurando-vidas
```

Instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run dev
```

Acesse no navegador:

```text
http://localhost:3000
```
